# Spidy Calculator

Create a complete working web calculator called "Web-Slinger Calculator" with an attractive retro superhero comic-book aesthetic inspired by the attached Spider-Man comic cover's visual mood: vintage red, cobalt blue, parchment cream, ink-black, halftone dots, dynamic comic panels, aged paper textures and bold comic typography. Do not copy Marvel/Spider-Man logos, character artwork, or exact cover lettering; use original generic web-slinger comic motifs made with CSS/SVG instead.

Use Lovable's React + TypeScript + Tailwind stack. Design should feel art-directed, exciting, and professional rather than a generic dashboard. Dark ink/navy background, cream comic panels, vivid red/blue and mustard accents, thick outlines, offset print shadows, subtle halftone dots, small original starbursts/web accents, responsive desktop/tablet/mobile layout. Main calculator is focal point.

Make the calculator buttons satisfying 3D physical comic buttons with visible side walls/extrusion, dark offset shadows, clear focus ring, hover lift, pressed-down animation. Digits on light parchment/blue, operators red or blue, equals a bright bold accent. Readable labels and accessible contrast. Header headline can say “THWIP! LET’S DO THE MATH.” plus small subtitle “YOUR FRIENDLY NEIGHBORHOOD CALCULATOR”.

Features: addition, subtraction, multiplication, division, decimal values, percentages, sign toggle, clear-all, backspace, chained operations, keyboard support, recent calculation history toggle and clear history, helpful visible error for division by zero. All interactions must work correctly, no login/database needed, robust calculation logic without eval, ensure expression/result behavior is reliable. Add tasteful motion but respect reduced-motion preference. Do not use the user’s uploaded comic cover as a background; use it only as stylistic reference. Keep the calculation logic cleanly separated so it can later be connected to a Java Spring Boot REST API; don't fake a backend API. Please build the actual app, not just a mockup, and validate responsiveness and interactions.
